# [Easy] 118. Pascal's Triangle

> **문제 링크:** [LeetCode - Pascal's Triangle](https://leetcode.com/problems/pascals-triangle/)

## 📝 問題説明
整数 `numRows` が与えられたとき、パスカルの三角形の最初の `numRows` 行を生成して返す問題です。

パスカルの三角形は次のようなルールを持っています：:
* 各行の最初と最後の数字は常に`1`です。
* それ以外の内部にある各数字は、すぐ上の行の左側の数字と右側の数字の合計で構成されます。

---

## 💡 アプローチ (Approach)

### 1. 直感的なアプローチ (Dynamic Programming / Simulation) - *最終通過した方法*
* **考えたロジック:** 三角形の構造上、$i$行を作るためには必ず直前の行である$i-1$行の情報が必要です。 したがって、前の行の隣接する2つの要素を加えながら現在の行を構築するシミュレーション方式でアプローチします。
* **解決手順:** 1. `i == 0` のときは最初の行なので、常に `[[1]]` で初期化します。
  2. `i > 0`のときからは、前の行（`res[i - 1]`）を参照して新しい行を作成します。
  3. 各行の中心に入る数字はリストコンプリヘンションを活用して実装します。 具体的には、`range(1, i)` の範囲のインデックス `j` に対して、前の行の `j-1` 番目の値と `j` 番目の値を足します（`res[i - 1][j - 1] + res[i - 1][j]`）。
  4. このように計算された中間配列の前後に両端の値`[1]`を付け加え、`(`[1] + [...] + [1]`)`res`配列に追加（`append`）します。

---

## ⏱️ 複雑性 (Complexity)

* **時間計算量 (Time Complexity):** $O(\text{numRows}^2)$
  * パスカルの三角形における総要素数は $\frac{\text{numRows} \times (\text{numRows} + 1)}{2}$です。 各要素を生成する際、前の行の2つの値を足す$O(1)$演算のみを行うため、全体の時間計算量は行の数の二乗に比例します。
* **空間計算量 (Space Complexity):** $O(\text{numRows}^2)$
  * 結果を保存して返すために三角形の2次元リストを保持する必要があるため、生成される全要素の数だけスペースが必要です。

## 💻 コードの要点まとめ（Key Code）
> 全体のコードは同じフォルダ内のソースコードファイル（`.py`、`/.java`など）で確認し、ここには核心的なアイデアや覚えておくべき部分だけを軽く書き留めます。

```python
# リストコンプリヘンションを利用したパスカルの三角形の核心実装
# 両端の[1]の間に、前の行(i-1)の二桁(j-1, j)を加えた値を埋める
for i in range(1, numRows):
    next_row = [1] + [res[i - 1][j - 1] + res[i - 1][j] for j in range(1, i)] + [1]
    res.append(next_row)
