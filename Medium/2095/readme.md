# [Medium] 2095. Delete the Middle Node of a Linked List

> **문제 링크:** [LeetCode - Delete the Middle Node of a Linked List](https://leetcode.com/problems/delete-the-middle-node-of-a-linked-list/)

## 📝 問題説明
単一の連結リスト（Singly-Linked List）のヘッドノード `head` が与えられます。 このリストから**中間ノードを削除**し、修正された接続リストのヘッドを返す問題です。

$n$ のサイズの連結リストの中間ノードは、整数の除算を用いて $\lfloor n / 2 \rfloor$ 番目のインデックス（0-indexed）に位置するノードとして定義されます。

* **例 1:** `head = [1, 3, 4, 7, 1, 2, 6]` $\でしょうね$ ノード数が7つなので、$\lfloor 7 / 2 \rfloor = 3$番目のインデックスである `7` を削除 $\でしょうね$ `(1, 3, 4, 1, 2, 6]` を返す。
* **例 2:** `head = [1, 2, 3, 4]` $\でしょうね$ ノード数が4つなので、$\lfloor 4 / 2 \rfloor = 2$番目のインデックスである `3` を削除 $\でしょうね$ `(1, 2, 4)` を返す。
* **例3:** `head = [2, 1]` $\でしょうね$ ノード数が2つなので、$\lfloor 2 / 2 \rfloor = 1$番目のインデックスである `1` を削除 $\でしょうね$ `(2)` を返す。

---

## 💡 アプローチ (Approach)

### 1. 直感的なアプローチ (Two-Pass) - *普通の方法*
* **考えたロジック:** リストを最初から最後まで一度巡回して、全ノードの数 $n$ を求めます。 その後、再び前から $\lfloor n / 2 \rfloor$ 番目のノードまで移動し、そのノードを削除します。
* **限界点:** リストを合計2回（Two-Pass）巡回しなければならないため、非効率的です。

### 2. 最適化されたアプローチ（Fast & Slow Pointers） - *最終通過した方法*
* **考えたロジック:** 2つのポインタを速度を変えて同時に移動させる**ウサギとカメ（Fast & Slow）**アルゴリズムを使用します。
* **解決過程:** 1. `fast`ポインターは一度に2マスずつ、`slow`ポインターは一度に1マスずつ移動します。
  2. `fast`ポインタがリストの終わり（`None`または最後のノード）に達したとき、1つずつ移動していた`slow`ポインタは正確に**リストの中間ノード**に位置します。
  3. 中間ノードを削除するには、その直前のノードの接続を切断し、次のノードに接続する必要があるため、`slow`に追従する`prev`ポインタを置いて前のノードを追跡します。
  4. ループが終了した後、`prev.next = slow.next` を実行して中間ノード（`slow`）をリストから除外します。

---

## ⏱️ 複雑性 (Complexity)

* **時間計算量 (Time Complexity):** $O(N)$
  * `fast`ポインタが2つずつスキップしてリストの最後まで移動するため、全体のノード数$N$に対しておおよそ$N/2$回だけ繰り返します。 つまり、一度の巡回（One-Pass）で解決されます。
* **空間計算量 (Space Complexity):** $O(1)$
  * `slow`、`fast`、`prev` の3つのポインタ変数だけを追加で使用するため、リストのサイズに関係なく一定のメモリ領域しか使用しません。

### 📍 Fast & Slow ポインターメカニズムの可視化


```python
# 1. ポインターの初期化
slow = head
fast = head
prev = None # slow の前のノードを追跡

# 2. ウサギ（fast）は2マス、カメ（slow）は1マスずつ移動
while fast and fast.next:
    prev = slow
    slow = slow.next
    fast = fast.next.next

# 3. 中間ノード（slow）削除：前のノード（prev）を次のノードに直接接続
# 예: 2(prev) -> 3(slow) -> 4  ===>  2(prev) -> 4
prev.next = slow.next
