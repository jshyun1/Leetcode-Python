# [Medium] 96. Unique Binary Search Trees

> **문제 링크:** [LeetCode - Unique Binary Search Trees](https://leetcode.com/problems/unique-binary-search-trees/)

## 📝 問題説明
`1`から`n`までのユニークな値を持つノードで構成できる**構造的にユニークなBST（二分探索木）の総数**を求める問題です。

* **例 1:** `n = 3` $\ -> 小さなテーブル `n = 3` 5つの固有の BST を作成できるので `5` を返す。
* **例 2:** `n = 1` $\ -> ノードが1つだけなので `1` を返す。

---

## 💡 アプローチ (Approach)

### 1. 直感的なアプローチ (Dynamic Programming) - *一般的な方法*
* **考えたロジック:** 各数字をルートノードに設定したとき、左のサブツリーと右のサブツリーが持つ可能性のある場合の数を求めて累積するDP（動的計画法）方式です。
* **限界点:** 二重ループを使用する必要があるため、時間計算量は$O(N^2)$となり、実装コードが相対的に長くなります。

### 2. 最適化されたアプローチ (Mathematical - Catalan Number) - *最終通過した方法*
* **考えたロジック:** 固有の二分探索木の数を求める問題は、数学で言う**カタラン数（Catalan Number）**の定義と正確に一致します。
* **解決過程:** カタラン数を求める公式は次の通りです:
  $$C_n = \frac{1}{n+1} \binom{2n}{n} = \frac{(2n)！}{(n+1)!n!}$$
  
  この公式は階乗（factorial）演算のみで構成されているため、Pythonの`math。factorial`を利用すれば、複雑なDPの実装やループなしで、1行の数学式で直接結果を計算できます。

---

## ⏱️ 複雑性 (Complexity)

* **時間計算量 (Time Complexity):** $O(N)$
  * `math。factorial(2n)`を計算するのに$O(N)$の時間がかかり、これは従来のDP方式の$O(N^2)$よりもはるかに効率的です。
* **空間の複雑さ (Space Complexity):** $O(1)$ または $O(N)$ (内部表現)
  * 別途の配列やハッシュテーブルを生成しないため、変数保存のための追加スペースは必要ありません。(ただし、大容量の階乗値を保存するためのメモリはシステム内部で使用されます。)
