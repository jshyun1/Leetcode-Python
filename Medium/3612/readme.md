# [Custom] String Processing Simulation（文字列処理シミュレーション）

> **問題リンク:** ユーザーが指定したカスタム問題（LeetCode類似スタイル）

## 📝 問題説明
与えられた文字列 `s` を最初から最後まで一文字ずつ順に回り、特定の特殊文字に出会うたびに指定されたルールに従って結果の文字列 `ans` を変形させるシミュレーション問題です。

### 📋 変換ルール
* **`*` (Backspace):** 現在までに積み重ねられた文字列の最後の文字を1つ削除します (`ans[:-1]`)。
* **`#` (Duplicate):** 現在までに蓄積された文字列全体をそのまま後ろにもう一度付加して、2倍にコピーします (`ans += ans`)。
* **`%` (Reverse):** 現在までに積み重ねられた全文字列を前後に反転させます (`ans[::-1]`)。
* **通常文字:** ルールに該当しない文字は、結果文字列の末尾にそのまま追加します (`ans += x`)。

---

## 💡 アプローチ (Approach)

### 1. 直感的なアプローチ (Simulation) - *最終通過した方法*
* **考えたロジック:** 文字列の各文字を線形探索($O(N)$)しながら条件文(`if-elif-else`)を通じて条件に合った文字列スライシングと演算を即座に行うシミュレーション方式です。
* **解決手順:** 1. 空文字列 `ans = ""` を初期化します。
  2. 入力文字列 `s` をループしながら文字 `x` を一つずつチェックします。
  3. `*`に出会ったら、Pythonの負のインデックススライス（`[:-1]`）を使って最後の文字を切り取ります。 文字列が空でも、Pythonのスライシングはエラーを出さずに空の文字列を保持するため、安全です。
  4. `#`に出会ったら、既存の文字列を自分と足して2倍に増やします。
  5. `%`に出会ったら、Pythonの逆順スライス（`[::-1`）を使って文字列を反転させます。
  6. それ以外の文字は累積演算子（`+=`）でそのままつなげます。

---

## ⏱️ 複雑性 (Complexity)

* **時間計算量 (Time Complexity):** 最悪の場合 $O(2^N)$ または $O(N^2)$
  * Pythonでは文字列は変更不可能（Immutable）なオブジェクトであるため、`+=`、`중から1つを取る`、`中から1つを取る`、`中から1つを取る`演算が行われるたびに新しい文字列がメモリに生成されます。
  * 特に`#`演算が連続して出ると、文字列の長さが指数関数的に増加し（`2倍`）、それに伴い文字列をコピーする時間も急増する可能性があります。 文字列の最終長さを $M$ とした場合、1 計算あたり最大 $O(M)$ がかかります。
* **空間計算量 (Space Complexity):** $O(M)$
  * 計算結果として生成される最終文字列 `ans` を保存するためのスペースが必要です。 文字列の特性上、中間演算過程でも新しい文字列が生成され続けるため、メモリ使用量が増加する可能性があります。

## 💻 コードの要点まとめ（Key Code）
> 全体のコードは同じフォルダ内のソースコードファイル（`.py`、`/.java`など）で確認し、ここには核心的なアイデアや覚えておくべき部分だけを軽く書き留めます。

```python
# 文字列スライシング技法を活用した条件別処理の核心
for x in s:
    if x == '*':
        ans = ans[:-1] # 最後の1文字を削除
    elif x == '#':
        ans += ans # 文字列全体 2倍コピー
    elif x == '%':
        ans = ans[::-1] # 文字列全体の反転（反転）
    else:
        ans += x # 一般文字を追加
